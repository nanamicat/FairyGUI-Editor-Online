# 浏览器插件

浏览器插件通过“工具 -> 浏览器插件”安装。安装项是一个 HTTP(S) 清单地址；编辑器会读取清单和 ESM 入口，校验大小与结构，并将新插件保持为停用状态。仅安装可信来源，启用前检查来源地址和权限列表。

## 权限

- `project.read`：接收当前选择及只读工程上下文。
- `project.write`：返回受限编辑命令；没有该权限时任何写命令都会被拒绝。
- `ui.menu`：在工具菜单注册命令。
- `ui.panel`：返回只读文本面板。

第一版写入能力仅允许修改当前单选对象有限范围内的 `position.x/y`。命令仍经过编辑器的校验、历史记录和保存流程；插件不能直接访问后端会话或工程文件。

## 沙箱

插件代码运行在受限 iframe 内的 Worker 中。宿主不向插件暴露 DOM、目录句柄、OPFS 工作区或当前 UAM；沙箱的内容安全策略禁止网络连接，单次调用限时 3 秒。插件只能接收其权限允许的序列化上下文，并返回已经声明的命令或面板结果。

清单和入口源码保存在当前浏览器的 `localStorage`。重新载入会从原地址获取新版本；来源内容可能变化，因此更新后应再次检查版本和权限。停用插件会销毁其当前沙箱。
