# 编辑工作流

## 工程生命周期

启动页、工具栏“导入”和“文件”菜单共用同一工作区流程：

- 文件夹：优先请求可写目录句柄；宿主不支持时降级为 `webkitdirectory` 只读导入。
- ZIP：支持未压缩条目，并在浏览器支持时解压 `deflate` 条目。
- 工作区：恢复当前 OPFS 或 IndexedDB 工程。
- 初始化：仅为空工作区写入默认样例。
- 保存：保存、重载并校验事务目标；存在文件夹绑定时再执行冲突检查和写回。
- 导出：生成可被同一导入器重新打开的 ZIP。

存在未保存修改时禁止切换、关闭或替换工作区。关闭操作只结束会话，不删除浏览器文件和最近使用记录。

## 文档与选择

从资源库打开组件时会创建或复用文档标签。标签、活动文档、逐文档选区与 `GroupPath` 可跨刷新恢复，但不进入工程历史。

画布支持单选、多选、框选、拖动、方向键微调、缩放、旋转、轴心、网格吸附、视图缩放和平移。指针移动时只更新临时投影，释放指针时才提交一个原子历史组；按 `Escape` 恢复提交前状态。

层级树排序、同包重设父级和跨组件重设父级复用 `detachDisplayNode -> attachDisplayNode` 原子批次。从资源库放置对象、复制/粘贴、创建副本和替换对象同样从当前 UAM 准备依赖与反向操作，不从运行时对象克隆工程数据。

## 属性检查器与面板

单选属性检查器提供对象通用属性及类型特有属性。多选只显示共同字段，混合值保持未填写或“保持当前值”；应用操作只提交实际变化字段。

控制器、动效、关联和齿轮属性编辑器先修改本地草稿，外层应用操作才提交一个完整的类型化操作。引用中的页面、目标、资源或控制器缺失时会在提交前拒绝。

时间轴与控制器面板直接读取当前 UAM。面板选择、时间轴焦点和测试播放状态只属于界面；修改控制器页面、动效项目或时间参数才进入撤销/重做和未保存状态检查点。

## 历史与保存

每次用户动作对应一个正向/反向操作组。撤销和重做按组执行，并在后端返回新快照后恢复仍存在的选区。保存只移动状态标识检查点，不清空撤销记录；撤销后提交新命令会清除重做分支。

保存成功必须同时满足存储写入、工程重载和事务目标后验。后验失败时保留未保存状态，不宣称保存完成。

## 运行时预览

编辑画布投影最新 UAM，并在可用时叠加已发布的运行时组件。新增节点或缺少发布包时使用可交互代理。资源字节、控制器、动效和齿轮属性修改会保持编辑画布可用，同时提示需要重新发布。

`TestView` 只实例化没有未保存修改且已经发布的组件。发布前必须先保存；未保存改动不会进入运行时包。
