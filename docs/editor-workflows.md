# 编辑工作流

## 工程生命周期

启动默认显示官方 UI 包的 `Builder/StartScene` 欢迎页，刷新不会自动进入示例或恢复编辑会话：

- 创建新项目：使用原版创建对话框，选择并授权目录后，在空目录或新子目录创建 LayaAir `.fairy` 工程。
- 打开项目 / 打开文件夹：通过一次 `showDirectoryPicker({ mode: "readwrite" })` 选择包含 `.fairy` 的工程目录并请求读写权限，然后复制到独立的浏览器工作区。不会覆盖此前工作区，不增加应用自己的第二次授权步骤，也不以只读导入副本替代目录授权。目录选择和访问确认的系统弹窗由浏览器控制。
- 最近打开项目：目录句柄存入 IndexedDB；首页预载句柄，点击项目时直接请求读写权限，再恢复浏览器工作区。重新选择同一工程目录时按句柄身份复用工作区，跳过目录扫描和复制，保留浏览器中已有内容和写回冲突基线。浏览器不会提供绝对磁盘路径，因此列表显示目录名和工程相对路径。授权记录丢失时需要重新选择目录。
- 历史重复记录执行一次性清理：同一工程根目录和 `.fairy` 路径优先保留当前工作区，否则保留最近打开项。清理备份原注册表并保留缓存文件；列表只显示注册表，不做展示去重。
- 取消或拒绝授权：保留首页和已有工作区。不把授权失败静默转换为只读导入。
- 目录选择器返回 `AbortError` 时明确提示“已取消或未获授权”，不继续显示等待。取得句柄后显示工程文件读取进度，跳过 `.objs` 等缓存和版本控制目录。
- 工程仅通过 File System Access API 打开和写回目录，不提供 ZIP 导入、ZIP 导出或文件夹只读导入。

目录选择器需要 HTTPS 或 localhost，以及支持 File System Access API 的 Chrome / Edge。选择目录和恢复授权都必须由用户点击触发，不能等待会话队列后再弹出权限请求。新建或选中本地项目不会自动覆盖已有文件；正常保存仍经过原有冲突检查和写回流程。

工具栏“导入”和“文件”菜单中的导入入口保留工作区替换预览流程：

- 文件夹：请求可写目录句柄；API 缺失、授权拒绝或取消时明确提示并停止，不降级为只读导入。
- 工作区：恢复当前 OPFS 或 IndexedDB 工程。
- 初始化：仅为空工作区写入默认样例。
- 保存：保存、重载并校验事务目标；存在文件夹绑定时再执行冲突检查和写回。
- 资源包和已发布运行时包仍使用各自的压缩格式，不属于整个工程的打开与保存入口。

存在未保存修改时禁止切换、关闭或替换工作区。关闭操作只结束会话，不删除浏览器文件和最近使用记录。

## 文档与选择

从资源库打开组件时会创建或复用文档标签。标签、活动文档、逐文档选区与 `GroupPath` 可跨刷新恢复，但不进入工程历史。

画布支持单选、多选、框选、拖动、方向键微调、缩放、旋转、轴心、网格吸附、视图缩放和平移。指针移动时只更新临时投影，释放指针时才提交一个原子历史组；按 `Escape` 恢复提交前状态。

层级树排序、同包重设父级和跨组件重设父级复用 `detachDisplayNode -> attachDisplayNode` 原子批次。从资源库放置对象、复制/粘贴、创建副本和替换对象同样从当前 UAM 准备依赖与反向操作，不从运行时对象克隆工程数据。

## 属性检查器与面板

单选属性检查器提供对象通用属性及类型特有属性。多选只显示共同字段，混合值保持未填写或“保持当前值”；应用操作只提交实际变化字段。

控制器、动效、关联和齿轮属性编辑器先修改本地草稿，外层应用操作才提交一个完整的类型化操作。引用中的页面、目标、资源或控制器缺失时会在提交前拒绝。

时间轴与控制器面板直接读取当前 UAM。面板选择、时间轴焦点和测试播放状态只属于界面；修改控制器页面、动效项目或时间参数才进入撤销/重做和未保存状态检查点。

## 历史与保存

每次用户动作对应一个正向/反向操作组。撤销和重做按组执行，并在后端返回新快照后恢复仍存在的选区。保存只移动状态标识检查点，不清空撤销记录；撤销后提交新命令会清除重做分支。

保存成功必须同时满足存储写入、工程重载和事务目标后验。后验失败时保留未保存状态，不宣称保存完成。

## 运行时预览

编辑画布投影最新 UAM，并在可用时叠加已发布的运行时组件。新增节点或缺少发布包时使用可交互代理。资源字节、控制器、动效和齿轮属性修改会保持编辑画布可用，同时提示需要重新发布。

`TestView` 只实例化没有未保存修改且已经发布的组件。发布前必须先保存；未保存改动不会进入运行时包。
